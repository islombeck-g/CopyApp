# CopyStack

Менюбар-приложение для macOS: запоминает всё скопированное текстом, по `⌘ .` показывает стек у курсора.

## Сборка и запуск

```bash
./build.sh --install   # собирает и ставит в /Applications
open /Applications/CopyStack.app
```

## Использование

- `⌘ .` — открыть/закрыть стек последних копирований (50 шт.)
- клик, `Enter` или `1`–`9` — выбрать; `↑ ↓` — навигация; `Esc` — закрыть
- Выбранный текст кладётся в буфер и вставляется (`⌘V`) в активное приложение

Автовставке нужен доступ: Системные настройки → Конфиденциальность → Универсальный доступ → CopyStack.
Без него текст просто окажется в буфере, нажми `⌘V` сам. После пересборки доступ может сброситься (ad-hoc подпись) — выдай заново.

История: `~/Library/Application Support/CopyStack/history.json` (права 0600). Данные из менеджеров паролей (`ConcealedType`) не сохраняются. Только текст, картинки/файлы не запоминаются.
